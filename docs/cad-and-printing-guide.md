# CAD 建模、3D 打印与浏览器内热替换指南

[← 返回文档中心](README.md) · [返回首页](../README.md)

MiniDuck-Edu Studio 内置全套 33 件参数化教学模型，开箱即用；同时也支持高校师生与机械工程师在 **Fusion 360 / SolidWorks / Onshape / Blender** 中自主设计或轻量化改进零件，并直接在浏览器内免代码热替换任意零件的 `.glb` / `.stl` 模型，完整保留爆炸动画、8-DOF 关节联动、X-Ray 透视与分步虚影高亮。

## 1. 自研结构件 CAD 建模与导出规范

### 1.1 关键装配接口尺寸与公差建议

为确保自研打印件与 MG90S、ESP32、PCA9685 实物顺滑装配，建模时建议严格遵守以下 FDM 桌面打印公差（以 0.4 mm 喷嘴为例）：

| 装配特征 | 标称实物尺寸 | 推荐 CAD 留隙尺寸 | 说明 |
| :--- | :--- | :--- | :--- |
| **MG90S 舵机安装槽** | `22.8 × 12.2 × 28.5 mm` | `23.2 × 12.5 mm`（单边 `+0.2 mm`） | 预留舵机出线豁口（`4 × 3 mm`），防止锁螺丝时压破三拼排线 |
| **MG90S 固定耳螺孔** | M2 自攻 / 机牙螺丝 | 自攻底孔 `Ø1.75 mm` / 通孔 `Ø2.2 mm` | 推荐使用 M2×8 螺丝，安装耳沉台深度 `2.5 mm` |
| **M3 铜柱 / 尼龙柱过孔** | M3 外径 `3.0 mm` | 通孔 `Ø3.2 mm` / 热熔螺母孔 `Ø4.2 mm` | 骨盆骨架（`MD-01`）与电控夹层（`MD-02`）四孔对称间距建议 `56 × 44 mm` |
| **外壳快拆卡扣 / M2.5 孔** | M2.5 螺丝 | 通孔 `Ø2.7 mm` / 沉头孔 `Ø5.0 × 2.0 mm` | 前胸壳（`MD-03`）与背盖（`MD-04`）侧锁，支持课堂 10 秒快拆检线 |
| **舵盘避让槽** | MG90S 白色一字/十字舵盘 | 宽度单边 `+0.25 mm`，中心沉孔 `Ø6.0 mm` | 先用 `1500 µs` 回中再套入舵盘并锁紧中心自攻钉 |
| **TPU 防滑底垫贴合槽** | `46 × 68 × 3.5 mm` | 鸭掌底面凹槽单边 `+0.3 mm`，深 `1.2 mm` | 可无胶过盈卡装或配合 3M 双面胶粘合 |

### 1.2 各主流 CAD 软件导出设置

| CAD 平台 | 推荐导出格式 | 导出单位与朝向设置 | 浏览器内默认缩放 (`scale`) |
| :--- | :---: | :--- | :---: |
| **Fusion 360** | **`.glb`** *(推荐)* 或 `.stl` | 导出 `.stl` 时单位选 `mm`、网格精度选 `Medium/High`；导出 `.glb`（需插件或经 Blender 转出）请将模型设为 **cm 或 m 并按需调缩放**、保留 PBR 材质 | `.stl` 自动 `0.1×`；`.glb` 自动 `1.0×` |
| **SolidWorks** | **`.stl`** 或经 Blender 转 `.glb` | `另存为 → STL → 选项`：格式选 **二进制（Binary）**、单位选 **毫米（mm）**、勾选「不要将 STL 输出数据转换到正空间」 | `.stl` 自动 `0.1×`（`mm → cm`） |
| **Onshape** | **`.glb` (glTF)** 或 `.stl` | 右键 Part Studio 零件 → `Export`：选 `GLTF`（二进制 `.glb`）或 `STL (Binary, Millimeter)` | `.stl` 自动 `0.1×`；`.glb` 自动 `1.0×` |
| **Blender** | **`.glb`** *(最精准)* | 1 Blender 单位设为 `1 cm`（或在导入后用滑块微调），导出 glTF 2.0 勾选 `+Y Up` 与 `Apply Modifiers` | `.glb` 自动 `1.0×` |

> **坐标系与居中说明**：`src/components/scene/CustomCadMesh.tsx` 在加载外部 `.stl`（`STLLoader`）和 `.glb`（`GLTFLoader`）时，会自动调用 `geom.center()` / `Box3().getCenter()` 将模型包围盒质心对齐至零件装配锚点，且自动补算顶点法线（`computeVertexNormals()`），因此无需担心 CAD 原点偏离世界原点导致零件飞出视野。

## 3. 浏览器内热替换 `.glb` / `.stl` 详细步骤

所有解析均在本地浏览器内存中通过 `URL.createObjectURL` 完成，**不会上传任何模型文件到远程服务器**，非常适合高校课程答辩、工业保密件评审与课堂实时迭代演示。

### 方式一：在「3D 爆炸装配图」右侧 Inspector 精细替换（推荐，支持实时调缩放）

1. 在顶部切换至 **「3D 爆炸装配图」** 视图，在 3D 画布中直接点击目标零件（或在右侧 **「零件速览与一键定位」** 搜索编号如 `MD-12`）。
2. 向下滚动右侧 **InspectorDrawer** 至 **「替换真实 CAD 模型 (.glb / .stl)」** 卡片，核对参考文件名（如 `MD12_head_beak.stl`）。
3. 点击虚线上传区，选择本地导出的 `.glb`、`.gltf` 或 `.stl` 文件。
4. 模型将立即在 3D 场景中生效，并自动继承该零件原本的：
   - 爆炸向量与虚线引线（`explodeVector`）；
   - 8-DOF 运动学父子挂载关系（例如替换 `MD-12` 橙嘴后，拖动 `CH6`/`CH7` 滑块鸭嘴照常随头部俯仰与偏航）；
   - `X-Ray 透视` 外壳透明（若属于外壳集合 `OUTER_SHELL_PART_IDS`：`MD-03`、`MD-04`、`MD-05R/L`、`MD-11`、`MD-12`、`MD-13`）；
   - `分步装机` 当前步高亮与后续步虚影状态。
5. 如发现模型偏大或偏小，使用展开后的 **「模型缩放倍率 (Scale)」** 滑块（`0.01× ~ 2.00×`）或 4 个快捷倍率按钮一键校准。
6. 点击 **「恢复默认」** 可随时卸载外部模型并回退至内置程序化网格（同时释放 ObjectURL 与 WebGL GPU 显存）。

### 方式二：在「BOM 与 CAD 替换」工作台批量管理

1. 切换至 **「BOM 与 CAD 替换」** 视图，在表格的 **「CAD 模型状态 (.glb/.stl)」** 列中，每一行零件都配有行内 **「替换 CAD」** 上传按钮。
2. 逐个替换多个自定义结构件后，顶部导航栏和 KPI 卡片会实时显示 **`CAD ×N`** 计数徽章。
3. 点击任意一行的 **「在 3D 中查看」**，即可一键跳转回 3D 视口聚焦检视替换效果。

## 4. 缩放比例约定与常见排错

由于 3D 场景的工程尺度严格定义为 **`1 scene unit = 10 mm (1 cm)`**，系统在 `src/App.tsx` (`handleUploadCad`) 中内置了智能默认缩放：

| 文件后缀 | 系统默认 `scale` | 适用导出单位 | 何时需要手动切换快捷按钮 |
| :--- | :---: | :--- | :--- |
| **`.stl`** | **`0.10×`** | 毫米 `mm`（Fusion 360 / SolidWorks / Onshape 默认 STL 单位） | 若原文件按 `cm` 导出，切至 `1.0×`；若按 `0.1 mm` 导出，切至 `0.01×` |
| **`.glb` / `.gltf`** | **`1.00×`** | 厘米 `cm` 建模导出 | 若 CAD 按标准 glTF **米（m）** 规范导出，零件会缩小 100 倍（仅约 0.08 单位）；若按 **毫米（mm）** 导出则会放大 10 倍，请点选 `0.1× mm→cm` |

### 常见排错

- **上传后显示红色线框立方体**：代表浏览器 `STLLoader` 或 `GLTFLoader` 解析失败。请检查文件是否为损坏的 ASCII STL、或引用了外部 `.bin`/纹理文件的非自包含 `.gltf`（请务必导出为单文件自包含的 **`.glb`** 或标准二进制 **`.stl`**）。
- **`.stl` 上传后没有颜色**：STL 格式本身不含材质信息，`CustomCadMesh.tsx` 会自动赋予与零件匹配的默认哑光材质（PLA 件为 `#F3EFE6` 象牙白，TPU 件为 `#1E242B` 炭黑）；如需展示多色外观或丝印，请优先导出 **`.glb`**。
- **刷新页面后自定义 CAD 消失**：出于纯前端隐私保护与零后端设计，上传文件仅驻留当前浏览器会话的 `Blob URL` 内存中，刷新即重置；如需永久固化为团队默认模型，请参考 [本地开发、二次扩展与自动部署](development-and-deploy.md)。
