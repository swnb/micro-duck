# 高校机器人课程实验手册（4 课时）

[← 返回文档中心](README.md) · [返回首页](../README.md)

本手册面向本科/研究生 **《机器人学基础》《机电一体化综合实验》《嵌入式控制系统》** 等课程设计，基于 **MiniDuck-Edu Studio** 交互式数字孪生工作台与 8-DOF MG90S 实体平台，形成 **“虚拟预演 → 实物装调 → 电控防呆 → 仿真拓展”** 闭环教学路径，共 **4 课时（每课时 45–90 分钟，可按周次拆分）**。

## 实验一：8-DOF 机械结构拆解与 90° 中位校准

### 1.1 教学目标

1. 理解双足机器人的 **6 腿部 + 2 头部** 串联运动链结构，辨识 Roll / Pitch / Yaw 三类正交旋转副的空间布置。
2. 掌握“先通电回 90° 中位，再锁紧舵盘”的工业装配规范，理解左右镜像安装时的软件极性反转（`invert = true`）。
3. 掌握 3D 打印零件壁厚、层纹受力方向（如 `MD-06R/L` 侧卧打印、`MD-07R/L` 侧面平躺抗弯）对结构强度的影响。

### 1.2 平台预演与实操步骤

1. **爆炸结构认知（10 min）**：
   - 打开平台默认视图 **「3D 爆炸装配图」**，将左侧 **全局爆炸系数** 从 `0%` 拖至 `100%`，并点击顶部 **`X-Ray 透视`** 与 **`坐标系/轴线`**。
   - 分别隐藏/显示 6 个子系统，指出 `MD-01`（主骨盆骨架）如何通过 4 根 `HW-01`（M3×22 铜柱/尼龙柱）与 `MD-02`（电控夹层）构建双层机电结构。
2. **8 步乐高式装机预演（15 min）**：
   - 切至左侧 **「分步装机」** 标签页，依次步进 **Step 01 → Step 08**，记录每步涉及的零件编号、紧固件规格与黄色 **工程要点**。
3. **MG90S 通电回中与实体装配（40 min）**：
   - **关键硬性流程**：在安装任何舵盘螺钉前，先由教师或助教核查供电后烧录 50Hz `1500 µs`（90°）中位脚本，待全部 8 颗 MG90S 转至中位后再断电装配。
   - 按 Step 1（`CH0`/`CH3` 髋侧摆）→ Step 2（`MD-06R/L` + `CH1`/`CH4` 髋前摆 + `MD-07R/L` 小腿）→ Step 3（`CH2`/`CH5` 踝侧摆 + 鸭掌与 TPU 防滑底垫）顺序组装下肢。
   - 装完后置于水平桌面，对照平台 **`零位站立`** 姿态，微调 `CH0–CH7` 软件 `Trim` 偏移量，使双脚 TPU 底垫完全平贴桌面无跷角。

### 1.3 思考与验收题

- **Q1**：为什么左髋前摆 `CH4` 与右髋前摆 `CH1` 施加相同 PWM 增量时，两条腿会朝相反方向摆动？在固件层应如何统一正方向？
- **Q2**：若装配时未先回 90° 中位便直接拧死舵盘，首次上电可能产生哪两种故障？（提示：软件限位错位、打齿/顶裂支架）

## 实验二：双足质心投影 CoM 与静态支撑多边形

### 2.1 教学目标

1. 掌握双足静态稳定判据：**整机质心（CoM）在支撑地面的垂直投影必须严格落入当前接地脚掌构成的凸包（Support Polygon）内部**。
2. 理解髋侧摆（`CH0`/`CH3`）与踝侧摆（`CH2`/`CH5`）的 **平行四边形反向协同机制**（$\theta_{\text{ankle}} \approx -\theta_{\text{hip\_roll}}$）。
3. 量化分析头部作为高处配重（`MD-11/12/13` + `SV-06/07`）对整机前后倾覆裕度的影响。

### 2.2 平台交互实验步骤

1. 在 **「3D 爆炸装配图」** 视图中，将爆炸系数设为 **`装配态 0%`**，确认顶部 **`重心投影`** 与 **`引线/标签`** 按钮处于开启状态，切换视角至 **`等轴测`** 与 **`俯视`**。
2. 切换左侧控制栏至 **「关节运动」** 标签页，依次点击 5 组预设姿态并记录地面 `CoM (X, Z) mm` 读数及支撑多边形颜色状态（绿=稳定 / 红=倾倒）：

| 预设姿态 | 关键关节角设定 | 支撑脚状态 | 预期观测现象 |
| :--- | :--- | :--- | :--- |
| **`零位站立`** | 全轴 `0°` | 双脚接地 | 绿色大凸包覆盖双脚，CoM 落于双脚几何中心附近 |
| **`重心左移`** | `r/l_hip_roll = +16°`, `r/l_ankle_roll = -16°` | 双脚接地 | 躯干平行左移且双脚保持水平贴地，CoM 水平移向左脚上方 |
| **`抬右腿迈步`** | `r_hip_pitch = -28°`, `l_hip_roll = +16°`, `l_ankle_roll = -16°` | 仅左脚接地 | 凸包瞬间收缩为左脚单掌多边形！观察 CoM 投影是否落于左脚掌内 |
| **`好奇张望`** | `r/l_hip_roll = -8°`, `neck_pitch = -18°`, `head_yaw = +36°` | 双脚接地 | 演示姿态表情与小幅侧倾下的稳定裕度 |
| **`低头巡检`** | `r/l_hip_pitch = -10°`, `neck_pitch = +28°` | 双脚接地 | 头部前俯带动 CoM 前移，髋部微后坐 (`-10°`) 实现前后配平 |

3. **破坏性稳定性对比实验**：
   - 先应用 **`抬右腿迈步`**，随后将 `l_hip_roll` 逐步拉回 `0°`（不侧移重心直接强行抬右腿），观察地面支撑多边形与 CoM 圆环何时由 **翠绿（`#059669`）** 突变为 **警示红（`#DC2626`）**，记录临界倾倒角。
4. **工程质量预算分析**：
   - 切至 **「BOM 与 CAD 替换」**，查看当前清单总重 `508.2 g` 与 `400 g` MG90S 稳态预算线的差距，结合 [轻量化减重方案](hardware-and-wiring.md#3-工程专题如何将整机减重压进-mg90s-400g-稳态预算) 拟定本组减重计划。

## 实验三：大电流供电隔离与 I2C 多设备总线调试

### 3.1 教学目标

1. 理解大电流执行器回路（`5V/5A UBEC → PCA9685 V+`）与弱电逻辑回路（`ESP32 3.3V → PCA9685 VCC & IMU`）隔离供电及星型共地的物理必要性。
2. 掌握双设备共享 I2C 总线（`PCA9685: 0x40` 与 `MPU6050: 0x68` / `BNO055: 0x28`）的接线、寻址与故障排查。
3. 建立严谨的实验室硬件上电前安全核查习惯。

### 3.2 平台联动与硬件实操步骤

1. **双屏 2D ↔ 3D 线束追踪（15 min）**：
   - 点击顶部 **「双屏教学联动」**，系统自动开启左侧 3D `X-Ray 透视` 与 `3D 线束`。
   - 在右侧 2D 电路域筛选栏中，逐一单独点亮 `7.4V 电池` → `5V 动力` → `逻辑供电` → `共地 GND` → `I2C 总线` → `PWM CH0–7` 六个域，对照左侧 3D 流动脉冲球明确每一束线的物理穿行路径与线规（`18AWG` / `22AWG` / `26AWG`）。
2. **实物接线与防烧板核查（30 min）**：
   - 切换至 **「2D 接线架构图」**，严格按照 19 条连线完成实物接线。
   - **助教签字关口**：在接通 2S 锂电池前，必须使用万用表完成右侧 **`SafetyChecklist`** 全部 4 项核查并逐项打勾（测量 `V+` 对 `GND` 阻值无短路、确认 UBEC 空载输出 `5.0V ± 0.1V`、核实共地导通、确认 `1000µF/10V` 电容极性无反接）。
3. **I2C 扫描与上电实测（25 min）**：
   - 断开电池总开关，仅用 USB-C 连接 ESP32 烧录 `i2c_scanner`（`SDA = GPIO21, SCL = GPIO22, 400kHz`），串口监视器应同时打印发现 `0x40`（PCA9685）与 `0x68`（MPU6050，升级版 BNO055 为 `0x28`）。
   - 拔除 USB-C 或确认防倒灌隔离后，打开电池总开关，逐通道对 `CH0–CH7` 执行 `±10°` 小幅扫频测试；有条件时用示波器对比加焊/未加焊 `1000µF` 电解电容时 `V+` 母线上的瞬间压降毛刺。

## 实验四：REP-103 URDF 导出与仿真环境衔接

### 4.1 教学目标

1. 理解图形学坐标系（Three.js Y-Up, cm）与机器人标准坐标系（ROS REP-103 Z-Up, m）的刚体置换关系。
2. 掌握从数字孪生工作台导出标准 URDF，并在 ROS 2 / RViz2 / Gazebo / MuJoCo 中加载、验证关节树与连杆惯量参数的完整流程。

### 4.2 实验步骤

1. **导出并审阅 URDF XML（15 min）**：
   - 进入 **「BOM 与 CAD 替换」**，点击 **「课堂 URDF 预览」**，审阅 9 个 `<link>`（`base_link`、`r/l_hip_u_link`、`r/l_shin_link`、`r/l_foot_link`、`neck_link`、`head_link`）与 8 个 `<joint type="revolute">` 定义，点击 **「导出标准 URDF (XML)」** 下载 `miniduck_edu_8dof.urdf`。
   - 核对导出参数：MG90S `effort="0.20"` N·m、`velocity="6.28"` rad/s、`damping="0.02"`、`friction="0.01"`，及各关节弧度上下限是否与角度限位表一致。
2. **坐标换算与父子相对偏置练习（25 min）**：
   - 验证导出器换算公式 $(x_{\text{rob}}, y_{\text{rob}}, z_{\text{rob}}) = (0.01 z_{\text{scene}}, 0.01 x_{\text{scene}}, 0.01 y_{\text{scene}})$。
   - **进阶工程改造**：由于基础导出器将世界基准 `pivot` 直接填入 `<origin xyz="..." />`，在 ROS / MuJoCo 多体树中子关节 `<origin>` 需表示为 **相对父关节坐标系的位移增量** $\Delta \mathbf{p} = \mathbf{p}_{\text{child}} - \mathbf{p}_{\text{parent}}$。请将以下 5 个子关节更新为相对偏移后保存为 `miniduck_edu_8dof_sim.urdf`：

| 子关节 | 父关节 | 世界基准 `pivot` (scene cm) | 相对父关节偏移 (scene cm) | REP-103 相对 `<origin xyz>` (m) |
| :--- | :--- | :---: | :---: | :---: |
| `r_hip_pitch` | `r_hip_roll` | `[-3.1, 5.6, -0.2]` | `[-1.0, -2.0, 0.0]` | `0.0000 -0.0100 -0.0200` |
| `r_ankle_roll` | `r_hip_pitch` | `[-3.1, 1.85, 0.1]` | `[0.0, -3.75, +0.3]` | `0.0030 0.0000 -0.0375` |
| `l_hip_pitch` | `l_hip_roll` | `[3.1, 5.6, -0.2]` | `[+1.0, -2.0, 0.0]` | `0.0000 0.0100 -0.0200` |
| `l_ankle_roll` | `l_hip_pitch` | `[3.1, 1.85, 0.1]` | `[0.0, -3.75, +0.3]` | `0.0030 0.0000 -0.0375` |
| `head_yaw` | `neck_pitch` | `[0, 15.6, 0.3]` | `[0.0, +1.9, +0.2]` | `0.0020 0.0000 0.0190` |

3. **仿真加载与自检（30 min）**：
   - 将自研或导出的 STL 网格放置于 `miniduck_edu/meshes/<link_name>.stl`（`scale="0.001 0.001 0.001"`）。
   - 在 ROS 2 环境运行 `check_urdf miniduck_edu_8dof_sim.urdf` 验证拓扑树无环且根连杆为 `base_link`；启动 `joint_state_publisher_gui` + `rviz2` 拖动 8 个关节滑块，对照平台 3D 视口验证旋转轴与正方向一致。
   - **选做拓展（研究生/竞赛组）**：将 URDF 转换为 MJCF 导入 **MuJoCo** 或 **Isaac Lab**，复现 `shift_left` → `step_right` 静态步态，或进一步升级为飞特总线舵机版开展 Sim-to-Real 强化学习训练。
